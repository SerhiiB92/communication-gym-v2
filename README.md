# Тренажер комунікації для менеджерів — MVP

Текстовий симулятор складних розмов (зриви дедлайнів, звільнення, конфлікти з клієнтами і
підрядниками) з ШІ-співрозмовником. 18 сценаріїв, 3 рівні складності, оцінка за 6 критеріями
наприкінці кожної розмови. Повністю безкоштовний стек.

## Стек

- Next.js 14 (App Router) + TypeScript
- Groq API (безкоштовний тариф, без прив'язки картки, OpenAI-сумісний API) —
  спочатку використовувався Gemini, але у Google зараз відомий баг з білінгом на
  безкоштовному тарифі (масові скарги на їхньому форумі), тому перейшли на Groq
- Без бази даних і авторизації — сесія анонімна, стан живе тільки в браузері
- Хостинг: Vercel (безкоштовний план)

## Локальний запуск

1. Встановіть залежності:

   ```bash
   npm install
   ```

2. Отримайте безкоштовний ключ на https://console.groq.com/keys (реєстрація через
   email або Google, картка не потрібна)

3. Скопіюйте `.env.local.example` у `.env.local` і вставте ключ:

   ```bash
   cp .env.local.example .env.local
   ```

   ```
   GROQ_API_KEY=ваш_ключ
   ```

   Без ключа застосунок все одно запускається і повністю клікабельний — API-роути
   повертають заглушки (DEV MODE), щоб можна було перевірити весь флоу без витрат.

4. Запустіть:

   ```bash
   npm run dev
   ```

   Відкрийте http://localhost:3000

## Деплой на Vercel (безкоштовно)

1. Заведіть репозиторій на GitHub і запуште туди код.
2. На https://vercel.com імпортуйте репозиторій (Add New → Project).
3. У Project Settings → Environments → Production додайте `GROQ_API_KEY` зі своїм ключем.
4. Deploy — Vercel сам визначить, що це Next.js проєкт.

Домен вигляду `your-project.vercel.app` буде готовий одразу після деплою, безкоштовно.

## Структура проєкту

```
app/
  page.tsx                 — список сценаріїв (головна)
  scenario/[id]/page.tsx   — бриф сценарію + вибір рівня складності
  chat/[id]/page.tsx       — чат з ШІ-персонажем
  result/page.tsx          — фінальний звіт і скоринг
  api/chat/route.ts        — репліка персонажа (виклик Groq)
  api/judge/route.ts       — фінальна оцінка розмови (виклик Groq)
lib/
  scenarios.ts             — 18 сценаріїв (контекст, характер, заперечення, прихований мотив)
  rubric.ts                — 6 критеріїв оцінки з якорями по відсотках
  promptBuilder.ts         — збирає системний промпт персонажа з урахуванням рівня складності
  judgePrompt.ts           — збирає промпт оцінювача з rubric + стенограмою
  llm.ts                   — обгортка над Groq API (з DEV MODE-заглушкою без ключа)
```

## Як це працює

1. Користувач обирає сценарій і рівень складності (1–3).
2. ШІ-персонаж сам починає розмову (перше повідомлення генерується автоматично).
3. Діалог триває до 20 реплік або до ручного завершення користувачем.
   Рівень складності визначає емоційність персонажа, кількість заперечень і те,
   чи розкриває персонаж прихований мотив ситуації.
4. По завершенні окремий виклик до Groq ("суддя") аналізує повну стенограму за
   рубрикою з якорями і повертає % за 6 критеріями + текстовий розбір
   (що вийшло добре / що покращити / практичні поради).
5. Результат зберігається лише в `sessionStorage` браузера — нічого не йде на сервер
   на постійне зберігання.

## Відомі обмеження MVP (свідомо відкладено на v2)

- Без реєстрації і збереження прогресу між сесіями
- Без дашборду прогресу за кілька сценаріїв
- Без голосу/відео/аватара — тільки текст
- Тільки десктоп-версія
- Rate limits безкоштовного тарифу Groq (30 запитів/хв, кілька тисяч на добу) можуть
  обмежити кількість розмов при активному використанні кількома людьми одночасно

## Як додати новий сценарій

Додайте новий об'єкт у масив `scenarios` у `lib/scenarios.ts` за тим самим форматом
(`id`, `category`, `titleUa`, `shortUa`, `contextUa`, `goalUa`, `characterNotes`,
`objectionsPool`, `hiddenMotive`, `escalationUp`, `escalationDown`) — інтерфейс і
логіка рівнів складності підхоплять його автоматично, код руками писати не потрібно.
